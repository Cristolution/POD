# POD Platform — Phase 3 Implementation Plan (Blade Views + Sand+Coral Theme)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the public-facing Blade views and self-management pages that consume the Phase 2 API. Every page renders the **Sand + Coral** brutalist design system — 3-5px borders, 0px radius, Archivo Black + Work Sans + Space Mono, coral `#FF6B4A` accent on warm sand `#F5EFE6`. No new server logic; pages are thin shells that fetch via the existing JSON API.

**Architecture:** Server-rendered Blade + progressive enhancement with Alpine.js for cart, dropdowns, modals, and search. The web session guard (not Sanctum bearer) handles authentication — when the user logs in we issue both a session cookie AND optionally a Sanctum token for API clients. Pages never call the API directly from Blade; they go through dedicated `Web\*` controllers that internally call the same Action classes (or query Eloquent directly for read paths).

**Tech Stack:** Laravel 13.8, Blade, Tailwind 4 (with custom Sand+Coral theme), Alpine.js 3, Vite, `spatie/laravel-permission` not used (we use the in-app `User::is*` helpers), `@livewire` not used (Alpine only), no Vue/React/Inertia.

**Phase boundary:** This phase builds **no admin pages**. `/admin` is Filament in Phase 4. This phase covers: marketing, catalog browsing, design detail, cart, checkout, customer account, designer dashboard, printer dashboard.

- [ ] **Step 1: Create the ShareUnreadCount middleware**

Create `app/Http/Middleware/ShareUnreadCount.php`:

```php
<?php

declare(strict_types=1);

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\View;
use Symfony\Component\HttpFoundation\Response;

class ShareUnreadCount
{
    public function handle(Request $request, Closure $next): Response
    {
        $user = $request->user();
        $count = $user
            ? $user->unreadNotifications()->count()
            : 0;

        View::share('unreadCount', $count);
        return $next($request);
    }
}
```

Register the alias in `bootstrap/app.php`:

```php
$middleware->alias([
    // ...
    'share.unread' => \App\Http\Middleware\ShareUnreadCount::class,
]);
```

- [ ] **Step 1: Create the BrowseController (talks to Eloquent directly)**

The public catalog reads are cheaper when served by Eloquent directly than by JSON→decode. Pattern is one controller method per browse page.

Create `app/Http/Controllers/Web/BrowseController.php`:

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers\Web;

use App\Http\Controllers\Controller;
use App\Models\{Category, Design, DesignerProfile};
use Illuminate\Http\Request;
use Illuminate\View\View;

class BrowseController extends Controller
{
    public function designs(Request $request): View
    {
        $query = Design::query()
            ->with(['designer', 'category', 'media', 'tags'])
            ->withCount('mappings')
            ->where('status', 'published')
            ->whereNull('deleted_at');

        if ($category = $request->string('category')->value()) {
            $query->where('category_id', $category);
        }
        if ($tag = $request->string('tag')->value()) {
            $query->whereHas('tags', fn ($q) => $q->where('slug', $tag));
        }
        if ($search = $request->string('q')->value()) {
            $query->where(function ($q) use ($search) {
                $q->where('title', 'like', "%{$search}%")
                  ->orWhere('description', 'like', "%{$search}%");
            });
        }

        $designs = $query->orderByDesc('created_at')->paginate(24)->withQueryString();

        return view('pages.browse.designs', [
            'designs'    => $designs,
            'categories' => Category::orderBy('name')->get(),
        ]);
    }

    public function categories(Request $request): View
    {
        $categories = Category::withCount('designs')
            ->with(['children'])
            ->whereNull('parent_id')
            ->orderBy('name')
            ->get();

        return view('pages.browse.categories', compact('categories'));
    }

    public function designers(Request $request): View
    {
        $designers = DesignerProfile::query()
            ->with(['user', 'designs' => fn ($q) => $q->where('status', 'published')])
            ->withCount(['designs' => fn ($q) => $q->where('status', 'published')])
            ->orderByDesc('designs_count')
            ->paginate(24);

        return view('pages.browse.designers', compact('designers'));
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers\Web;

use App\Actions\Cart\{ClearCartAction, DeleteCartItemAction, UpdateCartItemQuantityAction, UpsertCartItemAction};
use App\Http\Controllers\Controller;
use App\Models\CartItem;
use App\Services\CartPricingService;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\View\View;

class CartController extends Controller
{
    public function __construct(
        private readonly UpsertCartItemAction $upsert,
        private readonly UpdateCartItemQuantityAction $updateQty,
        private readonly DeleteCartItemAction $delete,
        private readonly ClearCartAction $clear,
        private readonly CartPricingService $pricing,
    ) {}

    public function show(Request $request): View|RedirectResponse
    {
        if (! $request->user()) {
            return redirect()->route('login', ['redirect' => route('cart.show')]);
        }

        $items = $request->user()->cartItems()->with(['mapping.design', 'mapping.template', 'variant'])->get();

        return view('pages.cart.show', [
            'items'      => $items,
            'grandTotal' => $this->pricing->grandTotal($items),
        ]);
    }

    public function store(Request $request)
    {
        abort_unless($request->user(), 401);

        $data = $request->validate([
            'design_product_mapping_id' => ['required', 'exists:design_product_mappings,id'],
            'product_variant_id'        => ['nullable', 'exists:product_variants,id'],
            'quantity'                  => ['required', 'integer', 'min:1', 'max:100'],
        ]);

        $this->upsert->execute(
            user: $request->user(),
            mappingId: $data['design_product_mapping_id'],
            variantId: $data['product_variant_id'] ?? null,
            quantity: $data['quantity'],
        );

        return redirect()->route('cart.show')->with('status', 'Added to cart.');
    }

    public function update(Request $request, CartItem $item): RedirectResponse
    {
        abort_unless($item->user_id === $request->user()?->id, 403);

        $data = $request->validate([
            'quantity' => ['required', 'integer', 'min:1', 'max:100'],
        ]);

        $this->updateQty->execute($item, $data['quantity']);

        return redirect()->route('cart.show');
    }

    public function destroy(CartItem $item): RedirectResponse
    {
        abort_unless($item->user_id === auth()->id(), 403);
        $this->delete->execute($item);
        return redirect()->route('cart.show')->with('status', 'Item removed.');
    }

    public function clearAll(): RedirectResponse
    {
        $this->clear->execute(auth()->user());
        return redirect()->route('cart.show')->with('status', 'Cart cleared.');
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers\Web;

use App\Actions\Order\PlaceOrderFromCartAction;
use App\Http\Controllers\Controller;
use App\Models\Order;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\View\View;

class CheckoutController extends Controller
{
    public function __construct(private readonly PlaceOrderFromCartAction $place) {}

    public function showAddresses(Request $request): View|RedirectResponse
    {
        $user = $request->user();
        if ($user->cartItems()->doesntExist()) {
            return redirect()->route('cart.show')->withErrors(['cart' => 'Cart is empty.']);
        }

        $addresses = $user->addresses()->orderByDesc('is_default')->get();
        return view('pages.checkout.addresses', compact('addresses'));
    }

    public function showReview(Request $request): View
    {
        $data = $request->validate([
            'shipping_address_id' => ['required', 'exists:addresses,id'],
            'billing_address_id'  => ['required', 'exists:addresses,id'],
        ]);

        $user = $request->user();
        abort_unless(
            $user->addresses()->whereIn('id', [$data['shipping_address_id'], $data['billing_address_id']])->count() === 2,
            403
        );

        $items = $user->cartItems()->with(['mapping.design', 'mapping.template', 'variant'])->get();

        return view('pages.checkout.review', [
            'items'              => $items,
            'shippingAddressId'  => $data['shipping_address_id'],
            'billingAddressId'   => $data['billing_address_id'],
            'grandTotal'         => app(\App\Services\CartPricingService::class)->grandTotal($items),
        ]);
    }

    public function place(Request $request): RedirectResponse
    {
        $data = $request->validate([
            'shipping_address_id' => ['required', 'exists:addresses,id'],
            'billing_address_id'  => ['required', 'exists:addresses,id'],
        ]);

        $order = $this->place->execute($request->user(), $data['shipping_address_id'], $data['billing_address_id']);

        return redirect()->route('checkout.confirmation', $order);
    }

    public function confirmation(Order $order): View
    {
        abort_unless($order->user_id === auth()->id(), 403);
        return view('pages.checkout.confirmation', ['order' => $order->load('items')]);
    }
}
```

```php
    public function showRegister(): View { return view('pages.auth.register'); }

    public function login(Request $request): RedirectResponse
    {
        $data = $request->validate([
            'email'       => ['required', 'email'],
            'password'    => ['required', 'string'],
            'device_name' => ['nullable', 'string', 'max:80'],
        ]);

        $result = $this->login->execute(
            email: strtolower($data['email']),
            password: $data['password'],
            deviceName: $data['device_name'] ?? 'web',
        );

        if ($result === null) {
            return back()->withErrors(['email' => 'Invalid credentials.'])->withInput();
        }

        [$user, $token] = $result;
        Auth::login($user);
        $request->session()->regenerate();

        // Optional: also persist Sanctum token in cookie for API client convenience
        cookie()->queue(cookie('pod_token', $token, 60 * 24 * 30));

        return redirect()->intended(route('account.dashboard'));
    }

    public function register(Request $request): RedirectResponse
    {
        $data = $request->validate([
            'name'                  => ['required', 'string', 'max:120'],
            'email'                 => ['required', 'email', 'unique:users,email'],
            'password'              => ['required', 'confirmed', Password::min(8)->mixedCase()->numbers()],
            'role'                  => ['required', 'in:customer,designer,printer_provider'],
        ]);

        [$user, $token] = $this->register->execute($data);
        Auth::login($user);
        $request->session()->regenerate();
        cookie()->queue(cookie('pod_token', $token, 60 * 24 * 30));

        return redirect()->route('account.dashboard');
    }

    public function logout(Request $request): RedirectResponse
    {
        auth()->user()?->currentAccessToken()?->delete();
        Auth::logout();
        $request->session()->invalidate();
        $request->session()->regenerateToken();
        cookie()->queue(cookie()->forget('pod_token'));

        return redirect()->route('home');
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers\Web;

use App\Http\Controllers\Controller;
use Illuminate\Auth\Events\PasswordReset;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Hash;
use Illuminate\Support\Facades\Password;
use Illuminate\Support\Str;
use Illuminate\View\View;

class PasswordController extends Controller
{
    public function showLinkRequest(): View { return view('pages.auth.forgot-password'); }

    public function sendLink(Request $request): RedirectResponse
    {
        $request->validate(['email' => ['required', 'email']]);

        $status = Password::sendResetLink($request->only('email'));

        return back()->with('status', __($status));
    }

    public function showResetForm(Request $request, string $token): View
    {
        return view('pages.auth.reset-password', [
            'token' => $token,
            'email' => $request->query('email'),
        ]);
    }

    public function reset(Request $request): RedirectResponse
    {
        $request->validate([
            'token'    => ['required'],
            'email'    => ['required', 'email'],
            'password' => ['required', 'confirmed', \Illuminate\Validation\Rules\Password::min(8)],
        ]);

        $status = Password::reset(
            $request->only('email', 'password', 'password_confirmation', 'token'),
            function ($user, $password) {
                $user->forceFill(['password' => Hash::make($password), 'remember_token' => Str::random(60)])->save();
                event(new PasswordReset($user));
            }
        );

        return $status === Password::PASSWORD_RESET
            ? redirect()->route('login')->with('status', __($status))
            : back()->withErrors(['email' => __($status)]);
    }
}
```
