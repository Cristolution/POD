## What to build (3 tasks)

### Task 1: Add `media()` relationship + accessor on User

**Files:**
- Modify: `app/Models/User.php` — add `media()` morphMany + `avatarUrl()` accessor + `initials()` accessor

**Add to User model:**
```php
use App\Models\Media;
use Illuminate\Database\Eloquent\Relations\MorphMany;

public function media(): MorphMany
{
    return $this->morphMany(Media::class, 'model');
}

public function avatar(): MorphMany
{
    return $this->media()->where('collection_name', 'avatar');
}

public function getAvatarUrlAttribute(): ?string
{
    $avatar = $this->avatar()->first();
    if ($avatar === null) {
        return null;
    }
    return \Illuminate\Support\Facades\Storage::disk('public')->url($avatar->file_path);
}

public function getInitialsAttribute(): string
{
    $words = explode(' ', trim($this->name ?? ''));
    $initials = '';
    foreach (array_slice($words, 0, 2) as $w) {
        $initials .= strtoupper(mb_substr($w, 0, 1));
    }
    return $initials ?: '?';
}
```

Test the relationship with tinker:

### Task 2: Avatar Blade partial

**Files:**
- New: `resources/views/components/ui/user-avatar.blade.php`

**Component props:**
- `user` (User model) — required
- `size` (string, default 'md') — one of `xs`, `sm`, `md`, `lg`, `xl`
- `class` (string, default '') — additional Tailwind classes

**Sizes (Tailwind classes):**
- `xs` → `w-6 h-6 text-xs`
- `sm` → `w-8 h-8 text-sm`
- `md` → `w-10 h-10 text-base`
- `lg` → `w-16 h-16 text-xl`
- `xl` → `w-24 h-24 text-3xl`

**Template:**
```blade
@props(['user', 'size' => 'md', 'class' => ''])

@php
    $sizeClasses = match ($size) {
        'xs' => 'w-6 h-6 text-xs',
        'sm' => 'w-8 h-8 text-sm',
        'md' => 'w-10 h-10 text-base',
        'lg' => 'w-16 h-16 text-xl',
        'xl' => 'w-24 h-24 text-3xl',
        default => 'w-10 h-10 text-base',
    };
    $url = $user->avatar_url;
@endphp

@if ($url)
    <img src="{{ $url }}" alt="{{ $user->name }}"
         class="rounded-full object-cover border-2 border-ink-800 {{ $sizeClasses }} {{ $class }}">
@else
    <div class="rounded-full bg-coral-500 text-white border-2 border-ink-800 flex items-center justify-center font-display {{ $sizeClasses }} {{ $class }}"
         aria-label="{{ $user->name }}">
        {{ $user->initials }}
    </div>
@endif
```

## Tests

**Test file:** `tests/Feature/Components/UserAvatarTest.php`

```php
public function test_renders_image_when_user_has_avatar(): void
{
    $user = User::factory()->create();
    Media::factory()->create([
        'model_type' => User::class,
        'model_id' => $user->id,
        'collection_name' => 'avatar',
        'file_path' => 'avatars/test.png',
    ]);

    $rendered = Blade::render(
        '<x-ui.user-avatar :user="$user" size="md" />',
        ['user' => $user]
    );

    $this->assertStringContainsString('<img', $rendered);
    $this->assertStringContainsString('avatars/test.png', $rendered);
}

public function test_renders_initials_when_no_avatar(): void
{
    $user = User::factory()->create(['name' => 'Lana Rivera']);
    $rendered = Blade::render(
        '<x-ui.user-avatar :user="$user" />',
        ['user' => $user]
    );

    $this->assertStringNotContainingString('<img', $rendered);
    $this->assertStringContainsString('LR', $rendered);  // initials
}

public function test_initials_handles_single_name(): void
{
    $user = User::factory()->create(['name' => 'Madonna']);
    $this->assertSame('M', $user->initials);
}
```
