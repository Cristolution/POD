API Endpoints

POD Platform · v1.2 · complete route surface · role-scoped · paired with PermissionMatrix-v1.2
How to read this doc. Every row is one HTTP route. Verb uses standard REST (GET / POST / PATCH / DELETE). Roles shows who may call the route — public (no auth), authenticated (any role), customer / designer / printer / admin (role-gated), or own (the record must belong to the caller). Path params indicate whether the ID is a UUID (the 9 public-facing tables) or a bigint (the 11 internal tables). Body / Returns lists the FormRequest fields expected and the API Resource shape returned.

Convention legend

MarkerMeaning
publicNo authentication required.
authenticatedAny logged-in user, regardless of role.
customerRole customer.
designerRole designer (own records unless specified).
printerRole printer_provider (own records unless specified).
adminRole admin (full access).
ownCaller must own the record (e.g. own cart_item, own design).
{uuid}CHAR(36) UUID — one of the 9 public-facing tables.
{id}Bigint integer — one of the 11 internal tables.

Cross-cutting conventions

  • Authentication — Laravel Sanctum bearer tokens. Token returned on register/login; sent as Authorization: Bearer ….
  • Validation — every write route uses a Store{Model}Request or Update{Model}Request. UUID FK fields use exists:table,id; enum fields use Rule::in([...]); unique fields ignore the current record on update via Rule::unique(...)->ignore($this->route('x')?->id).
  • Response shape — every resource returns via an App\Http\Resources\{Model}Resource extending JsonResource. Relations are lazy via whenLoaded; aggregates via whenCounted.
  • Errors — 401 unauthenticated, 403 forbidden, 404 missing, 409 conflict (e.g. delete-blocked by reference), 422 validation failure with field-keyed errors.
  • Pagination — list endpoints default to 25 per page, max 100. JSON response includes links + meta (Laravel default).
  • Filtering — query string filter[...] or flat keys (e.g. ?status=pending&from=2025-01-01). Sort via ?sort=-created_at (prefix - for desc).
  • Soft-delete — deleted records return 404 by default. Include them with ?include_deleted=1 (admin only).
  • Rate limiting — auth routes 10/min, write routes 60/min, read routes 300/min per token.
